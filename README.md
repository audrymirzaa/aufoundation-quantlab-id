# aufoundation-quantlab-id
QuantLab Indonesia oleh AUFOUNDATION: analisa harga saham IDX/IHSG (return, beta, CAPM, risiko, Standar Deviasi dan Korelasi Variasi) dipadukan dengan analisa fundamental sederhana (ROE, PBV, CR) sebagai pengembangan mandiri, berawal dari materi dosen mata kuliah Pasar Modal. Open-source dan siap difork untuk pasar negara lain.
